# Безопасное контактное взаимодействие манипулятора с человеком (CBF-фильтр для VLA)

## Идея и назначение проекта
Проект посвящён созданию и исследованию защитного слоя (CBF-фильтра) поверх VLA-политики управления манипулятором (`π0`), который ограничивает пиковую силу случайного контакта робота с человеком в рамках порогов безопасности ISO/TS 15066 при сохранении выполнения целевых задач.

## Область применения
Коллаборативная робототехника: работа манипулятора (или гуманоидного робота) в общем рабочем пространстве с человеком без жёстких защитных ограждений и без полной остановки при каждом сближении.

## Основные возможности (планируемые)
- Симуляция манипулятора и контактного взаимодействия с зонами тела человека в **ROS 2 Jazzy + MuJoCo** (с калибровкой по двухмассовой модели ISO/TS 15066).
- Фильтрация управляющих команд через **Control Barrier Function (CBF-QP)** по допустимой скорости сближения и пиковой силе контакта.
- Сравнение режимов безопасности: без фильтра, скоростной лимит (ISO 10218-1), геометрический CBF избегания столкновений и CBF по силе контакта.
- Оценка риска превышения допустимой силы контакта и доли успешно выполненных задач.
